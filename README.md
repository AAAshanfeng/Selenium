# Web自动化测试练习项目

基于the-internet.herokuapp.com练习站，使用Selenium + Pytest
完成登录、下拉框、弹窗、动态加载等典型场景的自动化测试。

## 技术栈
Python + Selenium + Pytest + WebDriverWait（显式等待）

## 测试范围
- 登录模块：正向/反向用例（账号密码错误场景）
- 下拉框选择与结果验证
- Alert弹窗：普通提示框、确认框（确认/取消）、输入框弹窗
- 动态加载内容：全程使用显式等待（WebDriverWait），未使用不稳定的time.sleep()

### 动态元素增删（数量变化验证）
- 连续添加3个元素，验证元素数量确实变为3
- 删除其中1个，验证剩余数量变为2（而非仅验证"删除按钮可点击"）
- 反向用例：初始状态下页面应无可删除元素

## 项目结构
fixture统一放在conftest.py中管理，测试用例按页面/功能模块拆分文件
